# 📌 About

This repository contains all the projects completed during my **Data Science Internship at CODSOFT**.

Throughout this internship, I worked on real-world Machine Learning projects involving data preprocessing, exploratory data analysis (EDA), feature engineering, model building, evaluation, and visualization.

The projects demonstrate my practical knowledge of Python, Data Science, and Machine Learning techniques.

---

# 🚀 Internship Projects

## ✅ Task 1 — Titanic Survival Prediction

Predict whether a passenger survived the Titanic disaster using Machine Learning classification techniques.

### Skills Used

- Data Cleaning
- Missing Value Handling
- Feature Engineering
- Logistic Regression
- Random Forest
- Model Evaluation

---

## ✅ Task 2 — Movie Rating Prediction

Predict movie ratings using historical movie information such as genre, actors, directors, duration, and votes.

### Skills Used

- Data Preprocessing
- Label Encoding
- Regression Models
- Feature Engineering
- Data Visualization

---

## ✅ Task 3 — Iris Flower Classification

Classify Iris flowers into three species using petal and sepal measurements.

### Skills Used

- Classification
- Data Visualization
- Logistic Regression
- Random Forest
- Confusion Matrix

---

## ✅ Task 4 — Sales Prediction using Python

Predict product sales based on advertising expenditure.

### Skills Used

- Linear Regression
- Feature Analysis
- Data Visualization
- Model Evaluation

---

## ✅ Task 5 — Credit Card Fraud Detection

Detect fraudulent credit card transactions using Machine Learning.

### Skills Used

- Handling Imbalanced Data
- StandardScaler
- Logistic Regression
- Random Forest
- ROC Curve
- Confusion Matrix
- Feature Importance
